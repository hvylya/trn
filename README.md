# Зал на двох

Офлайн-застосунок з програмою тренувань і трекером для Kotyk та Oksik.

- Відкрий адресу сайту в Safari на iPhone → «Поділитися» → «На початковий екран».
- Після першого відкриття працює без інтернету.
- Дані тренувань зберігаються лише на телефоні. Резервна копія — у налаштуваннях (⚙️).
